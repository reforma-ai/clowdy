# Brand marks

Marks of the agents and services Clowdy talks about. Logos and trademarks belong to their respective owners.

| Local file | Source |
| --- | --- |
| `claude..svg`, `openai.svg` | Match the [Simple Icons](https://github.com/simple-icons/simple-icons) paths of `claude` and `openai` (the Claude one keeps its brand colour). |
| `cursor.svg` | The 2D cube of Cursor's own brand kit, `General Logos/Cube/SVG/CUBE_2D_LIGHT.svg`, from the "Brand assets" zip on [cursor.com/brand](https://cursor.com/brand). Path data is unchanged; the `viewBox` is widened to a square so the mark sits in the same box as the others, and the fill is `currentColor` so it follows the theme. |
