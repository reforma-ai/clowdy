**Goal:** Give people who downloaded Clowdy a quiet way to star the repository, and give the app an About page that holds its links, the state of its daemon, and its credits.
**Approach:** Stages 1 to 3 are renderer code and a root script, so they ship over the air with no shell release. Stage 1 adds the Settings page and the repository links it and the card share; Stage 2 adds the one-time card to the chat list; Stage 3 generates the credits file the page links to. Stage 4 is the shell part (menu item, version fields) and waits for the next shell version bump.
Research: `research/index.md` (read it for file maps and constraints).

**Decisions**

- The card sits at the bottom of the chat list (left column of the Agents screen), under the scrolling list.
- The card shows when the personal project is at least 3 days old and the project on show has at least 3 chats (threads left out, archived chats counted). It is drawn in a development run too.
- Card text: title `Having a good time with Clowdy?`, under it `A star on GitHub helps us grow`, a `Star on GitHub` button and a close button. The button and the close button both close the card for good (`localStorage`, `clowdy:` key). The Help menu item and the About page link do not close it.
- The repository address is a constant (`https://github.com/reforma-ai/clowdy`) in `packages/constants`, with the releases page (`/releases/latest`) and the credits file (`/blob/main/THIRD-PARTY-LICENSES.md`) built from it. Links open in the system browser through `Button href target="_blank"`.
- Settings gets a page `About`, last in the sidebar, in a group of its own named `Clowdy`. Sections: Clowdy (links to the repository and to the releases page), Updates, Credits.
- Updates is built around hosts: a card per host, and today there is one host, `Local` (this computer, which is a host like any other). Its row shows the daemon's version from `GET /v1/health` (`Health.version`) and has no buttons. Remote hosts, a host picker and update actions come with the SSH feature and are not built now. The `Clowdy app` row (shell version and bundle number) arrives with Stage 4.
- Credits is one row that links to `THIRD-PARTY-LICENSES.md` on GitHub. The app carries no license texts and no viewer for them.
- `THIRD-PARTY-LICENSES.md` at the repo root is generated by a script from the production dependency closure of `apps/desktop` and `apps/daemon`, plus committed hand-written entries for what is not an npm package: Electron and Chromium, Bun, ripgrep, the Onest font, Material Icon Theme, the brand marks (with a trademark note). It stays in the repository and is not packaged. Bun's license is not shipped beside its binary.
- The native menu gets a Help menu with one item, `Star Clowdy on GitHub`, on macOS only (the Windows menu bar is hidden behind the custom title bar). It and the version fields are a shell change (Stage 4) and go out with the next shell version bump.
- UI text follows the root rule: a phrase or one sentence has no period; two sentences or more keep theirs.

**Reuse:** `chatListPreferences.ts` (the pattern for a per-install flag), `readStored`/`writeStored` (`stores/storage.ts`), `ShortcutsPage.tsx` and `settings/ui/*` (`SettingsPage`, `SettingsSection`, `SettingsCard`, `SettingsRow`), `Button` with `href` (`projects/ProjectFolders.tsx` `RemoteButton` is the in-app example of a link button), `Health` and `ROUTES.health` (`packages/protocol/src/api.ts`), `Alert` or `ReadOnlyNotice.module.css` for the plate look.

## Out of scope

- Shipping license texts inside the app, a viewer for them, Bun's license beside its binary, a CI check that `THIRD-PARTY-LICENSES.md` is current. Revisit if the link-only credits cause trouble.
- Remote hosts, the SSH deployment, a host picker, daemon update buttons and the "Check for updates" button.
- Clowdy's own license, `@clowdy/file-manager` being `UNLICENSED`, and the Reforma-derived code: to be decided before the repository opens. The credits file states nothing about Clowdy's own license.
- A star count, and any network call to GitHub.

## Stage 3 — The credits file

**Depends on:** None.

**This stage:** Replaces the hand-written one-entry `THIRD-PARTY-LICENSES.md` with a generated file the About page links to. A root script walks the production dependency closure of `apps/desktop` and `apps/daemon`, lists every package with its version, license and copyright line, and prints each distinct license text once. The entries that are not npm packages come from one committed file that the script copies in front. The file stays in the repository.

- [x] Complete
  - [x] `./clowdy licenses` writes `THIRD-PARTY-LICENSES.md` and is deterministic: a second run changes nothing
  - [x] The packages come from the production `dependencies` closure, each with version, declared license and copyright line, and a fallback for the four packages without a license file
  - [x] The hand-written entries (Electron and Chromium, Bun, ripgrep, Onest with its OFL text, Material Icon Theme, brand marks with the trademark note) live in one committed source file
  - [x] The generated file is committed, and the root `AGENTS.md` names the command

**Files**

- `scripts/licenses.ts` — create: a command like `scripts/worktree.ts`, one topic per file
- `scripts/cli.ts` — register the `licenses` command and its help line
- `scripts/licenses-extra.md` — create: the hand-written entries the script copies in; the current Material Icon Theme text moves here
- `THIRD-PARTY-LICENSES.md` — regenerated
- `AGENTS.md` — Tooling: one line for `./clowdy licenses`

**Done when:** `./clowdy licenses` produces a file that lists the 251 shipped npm packages or their closure (a few more is fine) with no package missing a license line, and every hand-written entry is present.
**Verify:** `./clowdy licenses` twice with no diff on the second run, a spot check of ten entries against their `package.json`, `bun run lint` and `bun run typecheck` at the root.
**Commits:** `a80f8a9` the `./clowdy licenses` command and the generated file (305 packages, a superset of the 251 shipped: it also lists declared dependencies no bundle pulls in, and optional peers); `a11fe9d` review fix: every line of a copyright notice is kept in the file.
